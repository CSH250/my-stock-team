# report-pptx — 종목 리서치 PPTX 생성 스킬

`reports/{종목명}.md` 를 읽어 **KB 톤으로 디자인된 PPTX**(`reports/{종목명}.pptx`)를 만든다.

## 실행 방법

```bash
# PPTX 출력
python ${CLAUDE_PLUGIN_ROOT}/skills/report-pptx/build_pptx.py "reports/삼성전자.md"
# PDF 출력 (같은 디자인·7페이지, A4 가로)
python ${CLAUDE_PLUGIN_ROOT}/skills/report-pptx/build_pdf.py "reports/삼성전자.md"
# 차트용 종목코드를 명시하려면 (PPTX·PDF 공통):
python ${CLAUDE_PLUGIN_ROOT}/skills/report-pptx/build_pptx.py "reports/삼성전자.md" --ticker 005930
```

- **PPTX 가 필요하면 `build_pptx.py`, PDF 가 필요하면 `build_pdf.py`** 를 쓴다. 둘 다 같은 `.md`·같은 디자인을 공유한다 (PDF 빌더가 PPTX 빌더의 파싱·차트 함수를 재사용).
- 이 환경엔 LibreOffice/PowerPoint 가 없어 PPTX→PDF 변환이 불가하므로, PDF 는 `.md` 에서 직접 그린다.

- 출력 파일명·종목명은 **입력 .md 의 파일명**에서 가져온다 (`삼성전자.md` → `삼성전자.pptx`).
- 종목코드는 본문에서 6자리 숫자를 자동 탐색한다. 못 찾으면 `--ticker` 로 넘긴다 (가격 차트에 사용).
- 여러 종목을 한 번에 만들려면 각 `.md` 마다 위 명령을 반복 실행한다.

## 슬라이드 순서 (항상 이 순서로 고정)

1. **표지** — 종목명 + 작성일 + "무료 공개 데이터 기반 학습용" 고지(자동)
2. **종목 개요**
3. **재무 요약** — 표(최근 3개년) + 코멘트
4. **가격 / 추세** — FinanceDataReader 6개월 차트(종가·20/60일선) + 코멘트
5. **뉴스 · 심리**
6. **리스크**
7. **한 줄 종합**
8. **데이터 출처 · 기준일** — `.md` 의 `## 데이터 출처` 섹션을 렌더(자동)

## 입력 .md 작성 규칙 (스킬이 잘 읽으려면)

- 맨 위 `# 종목명(코드)` H1, 본문 어딘가에 `기준일: YYYY-MM-DD` 를 둔다(작성일로 사용).
- 각 슬라이드는 **H2 헤딩(`## ...`)** 으로 구분하며, 헤딩에 아래 키워드가 들어가면 해당 슬라이드로 매핑된다:
  - 개요 → `## 종목 개요`
  - 재무/실적 → `## 재무 요약` (이 안에 마크다운 **표**를 넣으면 표로 렌더)
  - 가격/추세/기술 → `## 가격·추세`
  - 뉴스/심리/이슈 → `## 뉴스·심리`
  - 리스크/위험 → `## 리스크`
  - 한 줄/종합/결론 → `## 한 줄 종합`
  - 출처/Source → `## 데이터 출처` (가드레일: 출처·기준일 목록 필수)
- 표는 표준 마크다운 표(`| ... |`) 형식으로. 행이 많으면 자동으로 잘라 슬라이드를 넘치지 않게 한다.
- 맨 위 H1 바로 아래 `> 무료 공개 데이터 기반 학습용` 한 줄을 둔다(표지 고지는 코드가 자동으로도 넣음).

## 디자인 사양 (코드에 고정됨)

- 포인트색 **KB 옐로우 `#FFBC00`** + 본문 그레이(`#333`/`#666`)·화이트, 차분한 금융 리포트 톤.
- 한글 폰트 **맑은 고딕** 하나로 고정 (라틴·동아시아 폰트 모두 지정 → 글자 깨짐 방지).
- 표 헤더는 옐로우, 데이터행은 흰/연회색 줄무늬.

## 지켜야 할 원칙

- **수치엔 반드시 `(출처/기준일)` 표기**가 입력 .md 에 있어야 한다. 이 스킬은 새 수치를 만들지 않고 .md 내용만 옮긴다 — 출처 없는 숫자는 입력 단계에서 빼라.
- **매수/매도·목표가 단정 금지.** 표지/한 줄 종합 슬라이드 하단에 "투자 판단은 사람" 고지가 자동으로 들어간다.
- 표지에 **"무료 공개 데이터 기반 학습용"** 고지, 마지막에 **데이터 출처·기준일** 슬라이드/페이지가 자동 생성된다 (CLAUDE.md 가드레일).
- 차트 생성에 실패해도(코드 미탐지·네트워크 등) 리포트 생성은 계속되며, 가격 슬라이드는 텍스트 요약으로 폴백한다.

## 의존성

- PPTX: `python-pptx`, `matplotlib`, `finance-datareader`
- PDF: `reportlab`, `matplotlib`, `finance-datareader`

미설치 시:
```bash
pip install python-pptx reportlab matplotlib finance-datareader
```
