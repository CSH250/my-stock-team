# my-stock-team 📈

**"삼성전자 분석해줘" 한 마디면, AI 애널리스트 팀이 알아서 회사 실적·주가·뉴스·위험요소를 조사해 발표자료(PPT·PDF)까지 만들어 줍니다.**

주식 공부나 자료 정리를 도와주는 도우미라고 생각하시면 됩니다. (실습·학습용이고, "이거 사라/팔아라" 같은 투자 권유는 하지 않습니다. 판단은 본인이 합니다.)

---

## 이게 뭔가요?

이건 **Claude Code**(클로드 코드)라는 AI 프로그램에 끼워 넣는 **부가 기능(플러그인)**입니다.
한 번 설치해 두면, 평소처럼 AI에게 말을 거는 것만으로 아래 일을 대신 해줍니다.

- 📊 회사 **실적**(매출·이익) 정리
- 📈 **주가 흐름**(올랐는지 내렸는지) 분석
- 📰 최근 **뉴스와 시장 분위기** 요약
- ⚠️ 투자 시 알아둘 **위험 요소** 점검
- 📑 위 내용을 깔끔한 **발표자료(PPT·PDF)**로 자동 제작

마치 애널리스트 4명 + 리포트 디자이너가 한 팀으로 일해 주는 셈입니다.

---

## 설치하기 (딱 한 번만)

> 먼저 컴퓨터에 **Claude Code**가 설치돼 있어야 합니다. (사내 안내나 claude.com/claude-code 참고)

Claude Code를 켜고, 입력창에 아래 두 줄을 차례로 붙여넣고 실행하세요. 복잡한 설정은 없습니다.

```
/plugin marketplace add CSH250/my-stock-team
/plugin install my-stock-team@my-stock-team
```

- 첫 줄: "이 도구가 있는 곳을 등록해줘"
- 둘째 줄: "그 도구를 설치해줘"

설치가 끝나면 준비 완료입니다.

---

## 사용하기

설치 후에는 그냥 **말하듯이** 적으면 됩니다.

```
삼성전자 분석해줘
```

그러면 AI 팀이 순서대로 일합니다 👇

1. 실적·주가·뉴스 담당이 **동시에** 조사하고
2. 위험요소 담당이 **종합 정리**한 다음
3. 결과를 문서로 저장해 줍니다.

이어서 발표자료가 필요하면 이렇게 말하세요:

```
삼성전자 리포트 PPT로 만들어줘
```

→ 표지부터 실적표·주가 그래프·뉴스·위험요소·요약·출처까지 들어간 **PPT와 PDF 파일**이 만들어집니다. (다른 회사도 똑같이, 회사 이름만 바꿔 말하면 됩니다.)

---

## ⚠️ 딱 하나, 처음에 준비할 것 — 'DART 키' 받기

회사 실적·공시 정보는 금융감독원이 운영하는 **DART**라는 **무료 공개 사이트**에서 가져옵니다.
이걸 쓰려면 본인 이름으로 된 **무료 이용 열쇠(API 키)**를 한 번 발급받아야 합니다. (보안상 사람마다 따로 받아야 해서, 이 도구에는 미리 넣어둘 수 없습니다.)

**받는 방법 (5분, 무료):**

1. https://opendart.fss.or.kr 접속 → 가입 후 **인증키 신청** → 신청하면 바로 키(긴 영문·숫자 문자열)를 줍니다.
2. 받은 키를 AI에게 알려주고 "이 DART 키 넣어줘"라고 하면, AI가 알아서 안전한 위치에 저장해 줍니다.
   (이 키는 비밀번호 같은 것이라 남에게 공유하거나 인터넷에 올리면 안 됩니다.)

> 주가·뉴스·위험요소 분석은 키 없이도 됩니다. **실적·공시만 DART 키가 필요**합니다.

## 도움이 필요하면

설치나 사용 중 막히면, Claude Code 안에서 그냥 **"설치하다 막혔어, 도와줘"**처럼 물어보면 단계별로 안내해 줍니다.

---

### 작게 적어두는 약속 (가드레일)
- 모든 숫자에는 **출처와 날짜**를 함께 표기합니다. (출처 없는 숫자는 쓰지 않습니다)
- 확인이 안 되는 정보는 **"확인 불가"·"미확인"**으로 솔직히 표시합니다.
- **"사라/팔아라" 같은 단정은 하지 않습니다.** 판단에 필요한 근거만 정리해 드리고, 최종 결정은 본인 몫입니다.
